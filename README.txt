FOODBRIDGE FRONTEND INTERFACE ONLY

Files:
- index.html
- css/style.css
- js/script.js

HOW TO RUN:
1. Extract the FoodBridge_Interface folder.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. No XAMPP, PHP or database is needed for this interface-only version.

NOTE:
This is a static frontend preview. Login, registration, donation submission and database functionality are not connected yet. The sample food cards are demonstration content.
